Sistema visual base: paleta, tipografía, logotipo y componentes. Colores extraídos del logotipo real de Grupo Edima. Todo aquí vive también como tokens en tailwind.config.js.

Identidad

Logotipo

Logotipo oficial (icono de triángulos + wordmark). La variante con texto blanco es para fondos oscuros. No existe archivo con texto oscuro para fondos claros — aquí se recreó el wordmark en el color de marca; lo ideal es reemplazarlo por el vector oficial si existe.

Fundamentos

Paleta de color

Colores extraídos del logotipo real: primario teal (triángulo mayor, confianza y técnica), secundario azul cielo (triángulo de apoyo) y acento ámbar (triángulo pequeño, un solo punto de color cálido). Neutros cálidos, no blanco/negro puro.

Primario — brand.primary

Secundario — brand.secondary

Acento — brand.accent

Neutros — brand.neutral

Fundamentos

Tipografía

Lora para títulos (serif con carácter, transmite solidez editorial) + Karla para texto (sans limpio y muy legible). Fallback a fuentes de sistema si Google Fonts no carga.
